# Full-Stack Mastery Journey — Project Requirements

These projects are designed to make your ability stronger step by step. Do **not** treat them as résumé decorations or tutorial-copying exercises.

## Project progression

1. **Accessible Responsive Portfolio** — HTML/CSS/web fundamentals.
2. **Vanilla JavaScript Application** — browser programming and async JavaScript.
3. **TypeScript Application** — type modeling and safer application design.
4. **React Admin Dashboard** — modern frontend architecture.
5. **Tested Python CLI** — Python engineering fundamentals.
6. **Production-Style Backend System** — FastAPI, PostgreSQL, SQLAlchemy, Redis, API engineering.
7. **Evolving Full-Stack Product** — integration, authentication, security, testing, Docker, CI/CD, AWS, observability.
8. **Independent Production Capstone** — prove that you can design and own a system from zero.

## How to use these requirements

For every project:

1. Read the whole specification before coding.
2. Create your own implementation plan.
3. Design before building.
4. Use Git from the first commit.
5. Build features independently.
6. Test important behavior.
7. Debug your own mistakes.
8. Refactor after the first working version.
9. Write documentation.
10. Complete the **Definition of Done** before moving on.

You may use official documentation, references, and AI for explanations, code review, debugging ideas, and test ideas. Do not copy a complete tutorial project or keep AI-generated code you cannot explain.

## Difficulty progression

| Project | Main ability trained | Level |
|---|---|---|
| 01 | HTML/CSS/accessibility/responsive design | Beginner |
| 02 | JavaScript/DOM/HTTP/async/debugging | Beginner+ |
| 03 | TypeScript/type modeling/tooling | Intermediate- |
| 04 | React/frontend architecture/state/data/forms/testing | Intermediate |
| 05 | Python/program structure/testing | Intermediate |
| 06 | API/database/backend architecture | Intermediate+ |
| 07 | Full-stack production engineering | Advanced |
| 08 | Independent system ownership | Advanced+ |

A project is complete only when you can explain what you built, how data moves through it, why you chose the architecture, how you handle invalid input, how you test/debug/deploy it, what can fail, and what you would improve next.

**Target loop:** Build → understand → debug → test → secure → deploy → explain → improve.
