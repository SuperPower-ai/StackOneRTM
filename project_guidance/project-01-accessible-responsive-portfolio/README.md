# Project 1 Workshop — Accessible Responsive Portfolio

**Program:** Full-Stack Mastery · 2026  
**Pairs with:** Month 2 textbook · [specification](../../full_stack_project_requirements_2026/project_01_accessible_responsive_portfolio.md)  
**Stack:** HTML and CSS only  
**Level:** Total beginner of this stack who has Month 1 Git/terminal habits

This workshop is the **build companion**. The Month 2 textbook teaches the language. This folder teaches you to **ship Project 1** — from installing the environment to a public HTTPS URL.

If you follow **only these workshop chapters**, type every file, and replace the example name with yours, you will have a complete, modern, accessible, responsive portfolio that meets the specification.

---

## How to use this workshop

1. Read the [specification](../../full_stack_project_requirements_2026/project_01_accessible_responsive_portfolio.md) once, closed-book afterwards as a checklist.  
2. Open chapters **in order**. Do not skip environment.  
3. **Type** the code into **your** repository (`~/portfolio/` or similar). Do not drag the `reference/` folder onto GitHub and call it yours.  
4. After each chapter, look at the page in the browser **over HTTP**.  
5. When the site matches the spec, compare with [reference/](reference/README.md) — the complete exam build.  
6. Deploy. Put the HTTPS URL in your README.

**Wrong belief:** “The reference folder is my homework.”  
**Correct:** the reference is the **answer key after you have typed**. Recruiters can tell a cloned Sam Rivera.

## What you are forbidden to use

JavaScript is **not** this project. The mobile menu is a checkbox. Dark mode is a checkbox plus CSS.
